## Независимый пересчёт

Метод: официальный `geometry.py` (`snapshot` на каждом отсчёте), adjacency list по
`edges`, BFS от клиента до любого шлюза, клиентские пункты не используются как транзит.
Все 4 сценария × 720 отсчётов посчитаны за 1,6 с на ноутбуке, то есть ~0,4 с на сценарий.

Эти значения зафиксированы как golden-фикстуры в `10_FIXTURES.md`.

Команда воспроизведения (из корня репозитория):

```bash
python - <<'EOF'
import sys, collections
sys.path.insert(0, 'Расчетный модуль')
import geometry as g
for f in ['01_full_constellation','02_first_launch','03_satellite_outages','04_link_range']:
    s = g.load(f'Данные/{f}.json'); e = s['environment']
    clients = [x['id'] for x in s['ground_sites'] if x['role']=='client']
    gws = {x['id'] for x in s['ground_sites'] if x['role']=='gateway'}
    reach = {c: [] for c in clients}
    for t in range(0, e['horizon_s'], e['step_s']):
        adj = collections.defaultdict(set)
        for a, b, _ in g.snapshot(s, t)['edges']:
            adj[a].add(b); adj[b].add(a)
        for c in clients:
            seen = {c}; q = collections.deque([c]); found = False
            while q and not found:
                for v in adj[q.popleft()]:
                    if v in seen or v in clients: continue
                    seen.add(v)
                    if v in gws: found = True; break
                    q.append(v)
            reach[c].append(found)
    print(f, {c: round(100*sum(r)/len(r), 2) for c, r in reach.items()})
EOF
```

## Выводы аудита

1. Направление верное: документация закрывает все десять критериев.
2. Критерий «Алгоритмы маршрутизации» (15 баллов) требует поиск **и обновление** маршрута.
   BFS даёт только поиск. Политика удержания маршрута и резервные пути перенесены в v1.
3. LLM в интерфейсе баллов не даёт и создаёт риск ошибочных цифр перед техническим
   экспертом. Перенесён в roadmap как ассистент на tool-use поверх API.
4. Killer features избыточны: список сокращён до P0/P1, часть вырезана.
5. Инфраструктура полного состава оставлена по решению команды и обоснована через
   таблицу роста нагрузки (`06_STORAGE.md`).
6. Экраны и визуальный стиль остаются на усмотрение команды и в аудит не входят.
7. Мокапы уже показывают Землю сверху над полюсом: это полярная азимутальная проекция,
   реализуемая на Canvas 2D без изменения композиции. 3D-режим добавляется в тот же слот
   позже.
