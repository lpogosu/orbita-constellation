ОРБИТА

Расчёт временного графа спутниковой группировки: сквозная достижимость, причины разрывов связи и выбор устойчивой конфигурации.

Интерфейс подключается отдельным срезом. Пока доступны служебные endpoint:

  • /api/health — состояние сервисов и флаг degraded_mode
  • /api/version — версии API и расчётного ядра
  • /api/docs — OpenAPI
